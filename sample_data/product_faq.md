# Product FAQ

The dashboard supports CSV import for standard exports. Files should include a header row and use UTF-8 encoding. Large files may take longer to process.

The dashboard supports role-based access controls for team accounts. Admins can invite members, assign roles, and restrict workspace permissions.

Monthly export is available on business and enterprise plans. Customers on starter plans can export manually from the dashboard.

For login and two-factor authentication issues, users should verify device time, try backup codes if enabled, and contact support if they are locked out. Support should never ask for passwords or one-time codes.

For report export crashes, collect browser, workspace ID, screenshot or error message, export format, and approximate file size before engineering escalation.
