# Refund and Return Policy

Customers may request a refund or return within 30 days of delivery when the item is damaged, defective, or materially different from the product description. Proof such as order ID, delivery date, photo, or short description of the issue may be requested.

Refunds should not be approved automatically when the order cannot be verified, the customer is outside the return window, the item condition is unclear, or the request involves legal threats, chargebacks, payment disputes, or suspected abuse. These cases require manager review.

Support agents must never ask customers to send full card numbers, passwords, one-time codes, API keys, or private credentials. Billing verification should use invoice ID, order ID, account email, and last four digits only when required by approved payment workflow.

For damaged items within the return window, support may offer replacement, refund review, or return instructions after verifying order status and collecting a photo if needed.
